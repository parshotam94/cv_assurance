Assurance Classification Legend & Operational Semantics

Formal interpretations of assurance outcomes per cybersecurity standards

PASS

Requirement fully demonstrated through automated tests and empirical benchmark execution with zero unresolved failures.

PARTIAL

Capability exists and passes baseline checks, but exhibits known algorithmic boundaries or requires explicit metadata.

FAIL

Requirement is not currently demonstrated, failed automated tests, or requires unavailable runtime components.

UNAVAILABLE

Required information, weights, or reference populations are absent from the provided asset package.
